### Лидер-дифф ([F], results/leader_diff/deck_diff.md)

11+ из 19 Dragapult-команд топ-100 (рейтинги 1041–1217, вкл. #2 и его точный лист, из

**[H]** Идентичность листа у 11 команд ⇒ общий публичный источник; разброс рейтингов на
одном листе ⇒ значимая часть разрыва — агент, а не только лист.

### B1 — обученная оценка ([F], results/b1/)

- Датасет: 341,302 состояния из 1,000 решающих игр топ-команд (обе стороны; лидеры
  выигрывают 64%). Фичи — 87, векторайзер V16 (переиспользован без изменений).
- **AUC 0.833** на по-эпизодном сплите; по фазам: 0.68 (ходы 0–2), 0.88 (6–9), 0.90 (10+).
- Экспорт в C++: побитовая точность **1.2e-07** (фикстура), **1.47e-07** на 112 живых
  решениях (C++ векторайзер+форест против Python vectorizer+xgboost).
- Урок для истории: xgboost сравнивает признак с порогом во **float32**; numpy NEP-50
  (`np.float32 < np.float64` → float64) молча переворачивает пограничные сплиты —
  стоило трёх часов диагностики. C++ (`float < float`) корректен изначально.
